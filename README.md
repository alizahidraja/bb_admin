# bb_admin

Icon/photo-led no-code facade for the Branch Tech Manager of a restaurant POS.
Built for BunBites (Frappe/ERPNext v15 + URY).

- `bb_admin/www/menu.py` + `menu.html` — public menu page with cart + "Order on WhatsApp" (V1).
- `bb_admin/api.py` — hardened whitelisted methods (menu / availability / price / P&L / staff) with self-authorization.
